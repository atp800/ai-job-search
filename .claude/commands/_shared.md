# Verification checklist

Use the requested command or document guide for drafting and revision. Before handoff, the drafter checks the actual deliverables on disk:

- **Factual accuracy:** check names, dates, qualifications, metrics, scope of responsibility and current versus historical claims.
- **Targeting:** check the intended employer, role, application questions and explicit instructions.
- **Consistency:** reconcile claims across deliverables and remove accidental repetition.
- **Quality:** check spelling, grammar, placeholders, stated limits and the final rendered layout where applicable.

For employer-facing application material, finish with the separate independent inspection in `.claude/commands/_validate-application.md`.
